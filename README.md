# Data Engineering Mentorship

A practical Data Engineering mentorship program focused on problem solving, architecture, design trade-offs, implementation, and building scalable and reusable data platforms through real-world exercises.

## Goal

Develop a stronger and more structured approach to solving data engineering problems, from understanding a problem to designing and implementing a solution.

The focus is on reasoning, architectural decisions, trade-offs, implementation quality, and clear communication.

## Working Principles

- **Reasoning over answers** — there is usually no single correct solution.
- **Explicit assumptions** — missing information can be replaced with reasonable, documented assumptions.
- **Shared architecture** — exercises use Landing, Raw, Enriched, and Curated layers.
- **Built beyond the exercise** — implementations should be reusable and scalable.

## Exercise Process

Each exercise follows the same general process:

1. Problem provided
2. Design prepared
3. Design review
4. Solution implemented
5. Code reviewed
